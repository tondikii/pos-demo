# LarisPOS Copywriting

Semua teks UI pakai bahasa Indonesia yang **manusiawi, ringkas, dan dekat dengan keseharian UMKM** — seperti ngobrol sama pemilik warung, bukan dokumen korporat.

## Prinsip

1. **Ringkas dulu.** Label tombol maks 2-3 kata. Empty state: judul pendek + 1 kalimat bantu.
2. **Natural & hangat, tapi profesional.** Hindari jargon ("sinkronisasi berhasil" → "Data tersimpan"). Hindari terlalu formal ("Anda diharapkan" → "Kamu bisa" — tapi di dashboard formalitas sedang: "Anda" ok di konteks resmi akun/langganan).
3. **Actionable.** Setiap pesan kasih langkah berikutnya, bukan cuma status.
4. **Konsisten istilah.** Satu konsep satu kata: "shift" (bukan "sesi"), "outlet" (bukan "cabang" di UI), "void" (bukan "batal transaksi" di tombol — tapi jelaskan di modal), "struk" (bukan "receipt").
5. **No emoji.** Ikon = SVG (skill ui-ux-pro-max).

## Template Per Konteks

| Konteks | Pola | Contoh |
|---|---|---|
| Tombol utama | Kata kerja langsung | "Bayar", "Simpan", "Buka Shift", "Cetak Struk" |
| Empty state | "Belum ada X" + 1 kalimat solusi + CTA | "Belum ada transaksi. Transaksi yang kamu buat akan muncul di sini." |
| Error | Apa yang gagal + kenapa + solusi | "Stok ayam geprek tinggal 2. Kurangi jumlah atau pilih varian lain." |
| Sukses | Konfirmasi singkat | "Transaksi tersimpan. Struk siap dicetak." |
| Onboarding | Manfaat + 1 aksi | "Isi produk pertama — butuh kurang dari 1 menit." |
| Trial/langganan | Jelas + urgensi wajar | "Trial 14 hari. Tanpa kartu, tanpa kontrak." |
| Notifikasi | Fakta + tindakan | "3 transaksi menunggu sync. Tekan untuk kirim." |

## Kata yang Dipakai vs Dihindari

| Pakai | Hindari |
|---|---|
| Simpan / Tersimpan | Persist / Commit |
| Buka Shift / Tutup Shift | Mulai sesi / Akhiri sesi |
| Metode bayar | Payment method |
| Kelola | Manage |
| Laporan | Report (di teks) |
| Langganan | Subscription (di teks) |
| Kurang stok / Stok menipis | Low stock alert |
| Tidak bisa | Cannot |
| Coba gratis | Free trial (di teks Indonesia) |

## Landing Page

- Value prop utama: "POS F&B yang bikin laris, harga warung."
- Fokus manfaat (cepat, offline, laporan jelas), bukan fitur teknis.
- FAQ jawab keberatan nyata: harga, offline, printer, kontrak, keamanan.
- CTA konsisten: "Coba Gratis 14 Hari".

## Checklist Sebelum Kirim

- [ ] Tidak ada jargon/istilah Inggris di teks user-facing (kecuali istilah produk: POS, QRIS, PIN, Bluetooth)
- [ ] Setiap pesan error punya solusi
- [ ] Label tombol = kata kerja, bukan kata benda
- [ ] Empty state tidak kosong melompong (selalu ada CTA)
- [ ] Konsisten pakai tabel istilah di atas
